# 设置页导航

设置以一张连续页面展示。左侧索引按飞书连接、应用配置、窗口与桌面、链接打开方式、流程操作、软件更新排列，与分组标题一致。应用配置在配置数据可用时显示。

标题“设置”和说明保留在滚动区域上方。索引与全部设置卡片组成同一个独立滚动模块，点击索引只滚动模块内容，不带动标题和应用顶栏。鼠标滚轮、触控板、触摸及键盘可连续浏览全部设置，边界处不向外层页面穿透，沿用全局隐藏原生滚动条的规则。

点击索引平滑滚动到同页目标，定位期间保持目标高亮，避免经过其他分组时闪烁；用户主动滚轮、触摸或键盘滚动后立即恢复当前位置跟踪。索引固定在模块内；窄窗口改为顶部紧凑索引，定位时为索引预留空间，不遮住分组。遵循系统减少动态效果偏好，键盘定位将焦点交给目标分组。

索引复用应用主题。珍珠全息风格使用与主导航一致的虹彩渐变、玻璃表面及柔和描边，日间和暗黑均消费对应主题变量。

分组定位和切换工作页不卸载设置编辑器，保留未保存填写、自动保存过程和失败反馈。

参考 [VS Code 设置分组目录](https://code.visualstudio.com/docs/configure/settings#_settings-groups)和 [USWDS 页内导航](https://designsystem.digital.gov/components/in-page-navigation/)的分组、固定索引与当前位置提示，采用项目已有主题、卡片及控件样式。
