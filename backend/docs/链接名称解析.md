# 链接名称解析

业务字段统一支持「原始链接文字 → 飞书元数据 → 通用网页标题 → 原网址」的展示链路。Markdown、HTML、富文本超链接和附件已带名称时直接使用原文；裸链接接近可视区域后异步补全。名称与文件图标仅用于展示，点击仍使用原始 URL，查询参数和锚点保持完整。解析结果不写回工作项，也不参与同步业务变化或更新计数。

## 普通网页

后端读取公开 HTTP/HTTPS 网页，按 `og:title`、`twitter:title`、HTML `<title>` 的顺序取首个非空标题，支持 HTML 实体、BOM、HTTP 和 HTML 声明的字符集。标题作为纯文本渲染。不会执行网页脚本、读取浏览器 Cookie 或发送飞书项目凭证；只在登录后生成标题的页面可能无法解析。

## 飞书云文档

识别飞书 / Lark 的知识库、文件、文档、表格等资源。配置独立的环境变量 `FSTODO_FEISHU_DOCS_ACCESS_TOKEN` 后，知识库使用 `GET /open-apis/wiki/v2/spaces/get_node`，其他资源使用 `POST /open-apis/drive/v1/metas/batch_query` 查询元数据；POST 是读取元数据，不是远端业务写入。支持的 access token 类型及权限以官方接口文档为准，调用身份还必须拥有目标资源的访问权限。

该变量应由启动桌面程序的进程环境传入，值是有效的云文档 `user_access_token` 或 `tenant_access_token`；设置或更新后重新启动桌面程序。程序不负责申请或续期，也不把值写入配置、数据库、日志或前端。现有飞书项目 MCP token 属于另一套接口，不能填到这里或自动复用。

未配置授权、授权过期或接口失败时，继续尝试公开网页标题；无法确认有效标题时保留网址。飞书登录页和通用品牌标题不会冒充文档名。

官方契约：

- https://open.feishu.cn/document/server-docs/docs/wiki-v2/space-node/get_node
- https://open.feishu.cn/document/server-docs/docs/drive-v1/file/batch_query
- https://github.com/larksuite/oapi-sdk-python/tree/v2_main/lark_oapi/api
- https://ogp.me/

## 请求与缓存

仅接收不含账号密码的 HTTP/HTTPS 地址。每跳重定向都重新校验地址与 DNS 解析结果，并固定到已校验的公网 IP；本机、内网和链路本地地址不进行自动请求。云文档授权只发送到固定的官方 API 主机，授权请求不跟随重定向。

普通网络优先使用系统 DNS。如果代理网络返回 `198.18.0.0/15` Fake-IP，使用固定地址和 TLS 主机名的 AliDNS HTTPS 查询重新取得公网 A 记录，校验后再连接；不直接放行虚拟地址，也不对真实内网解析结果启用此回退。此情形会向 AliDNS 发送目标主机名，不发送完整网页 URL 或任何业务凭证。接口响应契约已通过实际查询核对。

进程内最多缓存 256 个结果，相同 URL（忽略片段）和授权身份的并发请求合并；成功缓存 24 小时，失败缓存 1 分钟。全局最多 4 个抓取任务，每个任务最长 8 秒（排队不计入），响应最多读取 1 MiB，公开网页最多请求 5 跳。退出程序即清空缓存；后台解析失败不弹错误，也不影响原始链接的打开操作。
