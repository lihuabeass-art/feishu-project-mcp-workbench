# 业务字段图文显示

业务字段支持 Markdown 内嵌图片、经过清理的 HTML 图片、图片附件数组及 `image` / `img` 等结构化图片节点。图文按字段内原顺序显示，普通网址保留链接，明确标记为非图片的附件保留文件链接。人员、状态和基础属性继续使用原有通用字段展示。

图片宽度适应详情区并保持比例，不裁切截图正文。进入可视区域附近才请求；点击打开大图，可用按钮缩放、指针拖动、重置位置，Esc 或关闭按钮退出。加载失败仅影响该图片，文字继续可读；重试会重新取得下载签名并绕过旧缓存。

## 下载与缓存

桌面 `load_field_image` 命令接收工作项复合身份、字段 key、原始图片 URL 和是否重试。后端首先确认对应详情快照的字段中确实包含该 URL。飞书项目主机的引用经 `get_download_url` 获取 `download_url` 与 `sign`，HTTP GET 只携带 `X-Meego-File-Sign`。MCP token 和下载签名不进入前端，前端只收到图片 data URL，沿用原有 CSP 的 `img-src 'self' data:`。

缓存位于数据库旁的 `<数据库文件名>.field-images-v1/`，按空间、类型、事项的 SHA-256 建立子目录，目录内再按事项、字段和原始 URL 的 SHA-256 分开存储。缓存有效时可离线读取；有效期 7 天，所有事项与旧版平铺图片共用 256 MB 上限。打开数据库或写入新图片时清理过期或最旧写入的文件；达到上限后淘汰旧图片，再次查看时重新下载。缓存写入失败不影响本次已下载的图片展示。旧版平铺图片读取时迁入事项目录，未再次读取的旧文件按原有效期清理。

只有完整成功同步、没有解析拒绝、并且事项已不属于任何来源时，才移除事项主记录并为详情和图片记录清理时间；失败、分页不完整、未启用的类型范围不会启动清理。详情和事项目录保留 7 天缓冲，期间事项重新同步到本地会取消清理；再次离开所有来源时重新计时。到期后的下次打开数据库或完整成功同步会删除详情快照与图片目录，文件占用等导致删除失败时保留记录并下次重试。图片自己的有效期和容量淘汰仍可能提前清除可重新下载的文件。升级前已有的孤立详情从首次打开新版时开始缓冲。SQLite 删除释放的页供后续复用，数据库文件体积不保证立刻缩小。

## 支持边界

- 预览支持 PNG、JPEG、GIF、WebP、BMP，通过响应类型及文件头检查，拒绝把登录页或其他文件当作图片；SVG 暂不预览。
- 单图上限保持 20 MB，按本次确认采用[飞书云文档插图限制](https://www.feishu.cn/hc/zh-CN/articles/172132728301-%E5%9C%A8%E6%96%87%E6%A1%A3%E4%B8%AD%E6%8F%92%E5%85%A5%E5%9B%BE%E7%89%87)；不套用飞书消息图片或项目通用附件的上限。下载具有配置中的请求超时。仅下载不含账号密码的 HTTPS 网络地址，不接受本地路径、localhost 或 IP 地址。
- 外部 HTTPS 图片由后端无凭证下载；重定向时不向其他主机转发签名。HTTP 图片保留为链接，不发预览下载请求。
- `is_multipart=true` 时明确提示在飞书中查看。本轮没有可核验的分片响应样本，未猜测分片结构。
- 仅有文件 token、没有 URL 的未知节点继续保留通用对象展示；当前工具需要 `file_url`。
- 缓存遵循本机已有数据的读取方式，不在每次离线查看时重新验证远端权限。

## 验证（2026-10-20）

使用本地已有详情快照中的真实 Markdown 图片（与用户给出的 URL 对应）核验 `get_download_url` 的元数据与响应。经新 Rust 图片入口成功下载 `image/png`，原始图片 458,350 字节；第二次读取命中本地缓存，与第一次返回的图片完全一致。此次验证只读取远端文件，没有修改飞书业务数据。

前端回归覆盖 Markdown 图文顺序、嵌套 HTML 中的 Markdown、附件与结构化图片、内容清理、可视区域加载、失败重试、图片解码失败、大图缩放关闭及焦点恢复、事项切换旧请求隔离、非图片附件链接。后端回归覆盖签名元数据解析、引用归属、图片文件头、缓存离线读取与跨字段/跨事项隔离。
